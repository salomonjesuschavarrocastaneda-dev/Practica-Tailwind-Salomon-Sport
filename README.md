# SALOMÓN SPORT

SALOMÓN SPORT es una tienda deportiva de presentación desarrollada como proyecto académico con HTML, Tailwind CSS v4 y JavaScript. El sitio presenta productos, servicios, información institucional, galería, preguntas frecuentes y un formulario de contacto con validación accesible.

## Objetivo

Crear una experiencia web moderna y responsive para una tienda deportiva realista, manteniendo una identidad visual negra, gris y dorada. El proyecto busca integrar diseño UX/UI, Tailwind CSS, interactividad con JavaScript, accesibilidad web y publicación mediante GitHub Pages.

## Tecnologías utilizadas

- HTML5 semántico.
- Tailwind CSS v4 mediante Play CDN.
- JavaScript moderno.
- Google Fonts.
- Recursos visuales externos de Unsplash.
- Git y GitHub.
- GitHub Pages para publicación estática.

## Características principales

- Diseño responsive para teléfonos, tabletas y equipos de escritorio.
- Navegación fija con menú hamburguesa.
- Modo claro y modo oscuro con preferencia guardada.
- Catálogo con seis tarjetas de productos.
- Indicadores visuales de productos destacados.
- Formulario con validación de nombre, correo electrónico y mensaje.
- Mensajes de error asociados a los campos.
- Toast de confirmación con desaparición automática.
- Acordeón accesible de preguntas frecuentes.
- Navegación mediante enlaces internos.
- Indicadores de foco y atributos ARIA.
- Animaciones y transiciones moderadas.

## Ejecutar el proyecto

### Visualización directa

1. Descarga o clona el repositorio.
2. Abre `index.html` directamente en el navegador.

### Servidor local con Live Server

1. Abre la carpeta del proyecto en Visual Studio Code.
2. Instala la extensión Live Server.
3. Haz clic derecho sobre `index.html`.
4. Selecciona **Open with Live Server**.

### Servidor local con Python

```powershell
cd C:\ruta\del\proyecto
python -m http.server 5500
```

Después, abre `http://localhost:5500`.

Todo el contenido, los estilos personalizados, Tailwind CSS y JavaScript de la interfaz se encuentran actualmente en `index.html`.

## Uso de inteligencia artificial

La interfaz y sus iteraciones de mejora fueron asistidas con herramientas de inteligencia artificial durante el desarrollo académico. La IA fue utilizada para generar propuestas de código, optimizar estilos responsive, mejorar la accesibilidad, validar comportamientos con JavaScript y preparar la documentación.

Los cambios finales deben revisarse, ejecutarse y mantenerse por el propietario del proyecto. Las imágenes, fuentes, scripts de Tailwind y otros recursos externos requieren acceso a internet.

La trazabilidad completa de las solicitudes utilizadas se documenta en [BITACORA_PROMPTS.md](BITACORA_PROMPTS.md).

## Publicación en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube los archivos `index.html`, `README.md` y `BITACORA_PROMPTS.md`.
3. Abre **Settings** > **Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama principal y la carpeta `/ (root)`.
6. Guarda los cambios y espera la publicación.
